本次已取得的证据：

- 23/23 个参考仓库拉取成功，commit SHA 记录在 [repositories.json](evidence/repositories.json)。这是浅克隆，适合当前版本调研，不包含完整历史。
- Tacit：41 项测试通过；类型声明构建失败；另行复现评分取整缺陷。
- AgentPair：选定的会话状态机、校验、预算扩展测试共 157 项通过；完整构建受缺失 `wasm-pack` 阻断。
- CSNP：294 项测试通过，3 项真实模型测试跳过；离线 CLI Demo 成功。
- LangGraph：SQLite checkpoint 在另一进程恢复成功。
- 官方 A2A Python SDK：ASGI 测试客户端经过实际 JSON-RPC 路由，完成 Agent Card 读取、input-required、同 task/context 继续、产出 artifact。

这些是组件可行性证据，不代表 X-Agent 完整产品已经实现。尚未验证两台机器互通、真实模型调用、完整浏览器闭环或生产部署。调研用脚本位于 `evidence/`，不应直接当作产品实现。
