# 3 分钟 Demo 脚本（双人 · 中文）

分工：**A 讲管理者视角（网页）**，**B 讲终端（用户视角）**。
启动一条命令：`bash scripts/demo_tui.sh` —— 网页自动播第一幕，终端四分屏待命；A 讲完，B 在终端按 Enter 开第二幕。

---

## A · 管理者视角（0:00–1:25）

〔动作：打开 demo 网页，自动播放〕

「每个人手机里都有一个越来越懂你的 agent。但 agent 和 agent 之间，互不认识。X-Agent 做的事情是：让你的 agent 替你去认识别人——先谈条件，再见真人。」

「这是管理者视角。池子里每个人的画像不是填表填的，是从他们自己的 agent 记忆里**蒸馏**出来的。就拿主角阿哲说，他画像里有三条硬的：只接受同城、抽烟是 dealbreaker、对要孩子持开放态度。」

「引擎先过硬门：沈亦舟在外地，出局；陆蔓抽烟，碰了 dealbreaker，出局。剩下的人做双向契合打分、调和平均合并——排名第一是林小满，0.935。」

「但注意，阿哲说了一句：『她太安静了。』外向程度立刻变成一条新偏好，重排之后，陈语桐升到第一，林小满掉到第三。**偏好不是一次填死的，是聊出来的。**」

〔交棒〕「名单有了。但系统觉得合适，不等于本人愿意。接下来，让四个 agent 自己去谈——交给终端。」

## B · 终端视角（1:25–3:00）

〔动作：切到终端，按 Enter 开始第二幕〕

「这里没有中央服务器。四个 agent 各跑一个进程，各自只拿着自己主人的画像，点对点谈。」

「阿哲的 agent 先广播需求：同城、不抽烟。候选人的 agent 在**本地**核对——原始画像不出门，对方只知道过、还是不过。隐私是协议保证的，不是口头承诺的。」

「谈着谈着出现一个问题：阿哲从没说过要不要对方对孩子开放。系统不编——它回到阿哲的窗口，**问真人**。阿哲一答，新条件实时同步给所有会话。候选人那边被问到没公开的信息，同理，问本人，不替主人乱答。」

「三份提案到齐，进入三选一。阿哲不看简历了，直接和候选人的 agent 聊——」

〔动作：在阿哲窗口输入 `@陈语桐 你周末一般怎么过？`〕

「对方用真模型回答，依据只有她本人的画像；画像里没有的，它会明说『这个得问本人』，更不会替主人答应见面。」

〔动作：输入 `/choose 陈语桐`〕

「阿哲选了陈语桐。另外两位收到婉拒——体面地拒绝，也是协议的一部分。陈语桐本人在她的窗口点了批准，**唯一一份见面提案**生成。」

〔收尾〕「今天演的是约会。同一套协议，换个场景，就是找合伙人、拼车、招人。我们想做的是 agent 时代的通讯录：你的 agent 先在网络上替你谈完条件，你只需要在最后一步，去见对的人。」

## 备注

- **手忙脚乱时**：用 `bash scripts/demo_tui.sh --auto-chat`，聊天自动问两个预设问题、自动选第一名陈语桐，全程不用手打。
- **真模型前提**：钥匙串里存好 key（`security add-generic-password -a "$USER" -s x-agent-llm -w`），`demo_tui.sh` 会自己读。
- **超时砍哪句**：先砍 A 的打分细节（双向打分/调和平均一句带过），B 的收尾愿景别砍。
- **评委追问备弹**：①真蒸馏——换成 glm-5.2 真蒸馏的画像，第一名会翻盘，蒸馏是「读法」不是真相；②稳定性——双边互评后可上 Gale-Shapley，保证没有 blocking pair；③规模化——管理者视角就是召回漏斗，粗排在前、细谈在后。
