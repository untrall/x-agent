# 3 分钟 Demo 脚本（双人 · 口语版）

分工：**A 讲管理者视角（网页）**，**B 讲终端（用户视角）**。
启动一条命令：`bash scripts/demo_tui.sh` —— 网页自动播第一幕，终端四分屏待命；A 讲完，B 在终端按 Enter 开第二幕。

---

## A · 管理者视角（0:00–1:25）

〔动作：打开 demo 网页，自动播放〕

「先说下我们做的是啥。现在每个人的 agent 都挺懂自己的，对吧，聊得越多越懂。但有个问题：我的 agent 不认识你的 agent。我们想解决的就是这个——让 agent 先替我们互相认识一下，条件聊拢了，人再见面。」

「先看管理者这一侧。池子里这些人的画像，不是谁填表填出来的，是从他们各自 agent 的聊天记录、记忆里蒸馏出来的。比如主角阿哲，他有三条是硬的：只找同城的，对方不能抽烟，还有，要不要孩子这件事得开放。」

「引擎先拿这三条过一遍：沈亦舟，人不在上海，直接没了；陆蔓抽烟，碰了红线，也没了。剩下的再算契合度打分，排出来第一是林小满，0.935，挺高的。」

「结果阿哲看了一眼，说了句：她太安静了。就这一句话，系统把『外向程度』加进去重新排——陈语桐上来了，林小满掉到第三。所以这个偏好不是一开始就定死的，是聊着聊着聊出来的。」

〔交棒〕「好，名单到这儿。但名单是系统排的，人家本人愿不愿意，还不知道。接下来就交给四个 agent 自己谈了，看终端。」

## B · 终端视角（1:25–3:00）

〔动作：切到终端，按 Enter 开始第二幕〕

「这边就没平台什么事了。四个 agent，四个进程，一个管一个人，互相之间点对点聊。」

「阿哲的 agent 先把要求发出去：同城、不抽烟。对方的 agent 就在自己本地对一下——对上了就说过，对不上就说不过。原始画像是不会发出去的，对方只知道结果。」

「聊到一半，卡了一下：阿哲到底要不要对方对孩子开放，他自己画像里没写。系统没替他编，直接弹窗问他本人。他说要，这个条件就实时同步到了所有正在聊的会话里。反过来也一样，候选人被问到没公开的事，也是回去问本人，agent 不自作主张。」

「三个人都谈完了，提案都在阿哲手里。这时候他不看分数了，直接跟对方的 agent 聊两句——」

〔动作：在阿哲窗口输入 `@陈语桐 你周末一般怎么过？`〕

「这个回答是真模型现场答的，但它只能用陈语桐画像里有的东西答；没有的，它会直接说，这个我得问她本人。它也不会替主人答应见面，这条是写死在协议里的。」

〔动作：输入 `/choose 陈语桐`〕

「最后阿哲选了陈语桐。另外两位会收到一个婉拒，就是，好好说一声的那种。陈语桐本人在她那个窗口点了同意，这才生成见面提案——全场就这一份。」

〔收尾〕「今天我们拿约会举例，其实这套东西换个场景也一样：找合伙人、拼车、招人。我们想做的，说白了就是 agent 时代的通讯录——先让 agent 在网上把条件谈完，你最后只需要出面，见那个对的人。」

---

## 备注

- **手忙脚乱时**：用 `bash scripts/demo_tui.sh --auto-chat`，聊天自动问两个预设问题、自动选第一名陈语桐，全程不用手打。
- **真模型前提**：钥匙串里存好 key（`security add-generic-password -a "$USER" -s x-agent-llm -w`），`demo_tui.sh` 会自己读。
- **超时砍哪句**：先砍 A 的打分细节（0.935 那句一句带过），B 的收尾别砍。
- **评委追问备弹**：①真蒸馏——换成 glm-5.2 真蒸馏的画像，第一名会翻盘，蒸馏是「读法」不是真相；②稳定性——双边互评后可上 Gale-Shapley，保证没有 blocking pair；③规模化——管理者视角就是召回漏斗，粗排在前、细谈在后。
