## 评审修正

A/B 交叉检查接口，独立 reviewer 通过内存 SQLite 复现并复核修复：合法拒绝进入终态；模型错误不无限重试；修订需求不留下无法回答的旧问题卡；本人已批准后不能再拒绝，防止双方结果分叉。协调器另检查并修正 owner/peer 凭证混用、输入框问题目标竞争、提案事实改写与同会话队列顺序。

## 明确边界

- Codex 真实模型已验收；独立 Chat Completions 服务仍待配置。模型决策仍有非确定性，不能将一次验收通过解释为稳定性或成本基准。
- 确定性模式解析场景配置中的语句模式及显式字段比较；不宣称任意自然语言理解。
- 当前协商是场景字段驱动的补问、拒绝、提案和批准；任意聊天、反提案、动态发现与标准 A2A 适配不属于本轮。
- 记忆支持用户明确保存的本人事实；跨请求偏好管理和复杂记忆检索未实现。
- 运行于本机 loopback，静态 peer 配置与演示凭证，不是公网生产部署。
- 旧版 Web 的异步身份切换问题没有在本轮改造；本轮 TUI 每进程固定本人身份。
